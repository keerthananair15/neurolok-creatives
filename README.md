# Neurolok Studio

Analyze the uploaded Neurolok Product Blueprint and logo carefully before designing. Build the actual Neurolok AI creative web app — not a marketing website. Follow the client’s features and UX requirements exactly, especially the unified Pilot/Director creation workflow, image/video generation, campaigns, storyboards, characters, trends and library.

Create a minimal, premium and highly intuitive UI with zero confusion for first-time AI users, while keeping advanced controls accessible through progressive disclosure.

Visual direction: deep black + emerald/neon green, subtle green gradients, refined liquid-glass/frosted-glass surfaces, soft glow, cinematic media, clean typography and restrained animations. Use the uploaded logo as the brand identity.

Prioritize strong UX, clear hierarchy, spacious layouts, simple natural-language creation, media-first results and a polished futuristic creative-studio feel. Avoid clutter, excessive glass, generic SaaS dashboards and unnecessary UI elements.
